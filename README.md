# Power BI Journey

My learning journey into Power BI, as part of my path to becoming a data scientist.

I am documenting everything I learn here: notes, practice files, and dashboards. The repo is updated at the end of every week.

**Started:** 13 October 2026

---

## About me

I graduated in marketing from Azerbaijan State University of Economics and I am moving into data science. I already work with Python, pandas, NumPy, Excel, and machine learning models. Power BI is the next tool I am adding, so I can turn data into dashboards that people can understand and use.

## Goals

- Learn to load, clean, and model data in Power BI
- Build clear and interactive dashboards
- Learn basic DAX (formulas for calculations)
- Finish with a portfolio-ready dashboard project

## What I am learning

- **Power Query:** cleaning and preparing data
- **Data modeling:** connecting tables with relationships (fact and dimension tables)
- **Visualization:** charts, cards, slicers, and layout
- **DAX:** measures and simple calculations
